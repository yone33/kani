# KANI 株式ポートフォリオ

国内株の取引CSVから、保有株の評価損益、売却損益、配当を確認できるローカルサイトです。

## Windowsでダブルクリック起動

1. [配布用ZIP](https://github.com/yone33/kani/archive/refs/heads/main.zip)をダウンロードし、右クリックで「すべて展開」を選びます。
2. 展開先の `Start-Portfolio.cmd` をダブルクリックすると、既定のブラウザでサイトが開きます。使い終わったら起動時の黒いウィンドウを閉じます。

64ビットWindows（x64／ARM64）が対象です。初回は公式の組み込み版Pythonをインターネットから自動取得してユーザー領域に保存するため、Pythonの事前インストールや管理者権限は不要です。2回目以降は保存済みのPythonを使います。株価・配当などの市場データ取得にはインターネット接続が必要です。

別のPCには展開前のZIPを送れます。取引データを使う場合は、移行先のブラウザでCSVを選択します。手入力の配当は入力したブラウザに保存されます。

## ローカル起動

Python 3.9以降と、現在の Chrome・Edge・Firefox・Safari を使います。外部Pythonパッケージは不要です。

1. リポジトリをクローンするか、ZIPをダウンロードして展開します。
2. Windowsでは、`server.py` があるフォルダーで次のコマンドを実行します。

   ```powershell
   py -3 server.py
   ```

   macOS・Linuxでは `python3 server.py` を実行します。
3. ブラウザで [http://127.0.0.1:8000/](http://127.0.0.1:8000/) を開きます。
4. 右上の **CSV** メニューから既存の取引CSVを選びます。サーバーは Ctrl+C で終了します。

## CSV

`株数` と `購入数` の両方に対応し、列順は自由です。UTF-8（BOM付き含む）とShift_JIS／CP932を読み込めます。既存CSVはブラウザ内で読み取り、元のファイルを変更しません。エラー一覧には行番号と項目名が出ます。有効な取引行は表示されます。

[空のテンプレート](web/template.csv)と[記入例](web/example.csv)はサイト内からもダウンロードできます。部分売却の行には売った株数と売却情報を入れ、保有分は売却欄が空の行として扱います。同一内容の行も加算します。取引一覧は再読み込みするとCSVの再選択が必要です。

## 市場データと配当

ローカルサーバーが銘柄コードを使って Yahoo!ファイナンスの東証銘柄ページを照会します。市場データの取得にはインターネット接続が必要です。照会には取引内容を含めません。サイトに表示する株価の時点は Yahoo!ファイナンスの表記です。

公開配当の四半期欄は決算月から対象の月末に対応付けます。決算期変更で中間の対象期末を確定できない項目や、公開表から内訳を確認できない金額は合計から除外します。購入日は含み、売却日は除いた対象期末時点の株数で税引前の配当額を推計します。実際の受取額には権利付き最終日、株式分割、税金などが影響します。年間予想配当は参考値です。

公開情報の不足分は銘柄詳細の配当履歴で追加できます。入力は同じブラウザのローカルストレージに保存され、同じ日付の公開値より優先されます。手入力を削除すると公開値が再び使われます。
